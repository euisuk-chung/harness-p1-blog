## 7. 넣는 것 · 나오는 것 · 지키는 것 (고정 칸 · 5차시)

> 이 절의 값은 받은 그대로 둡니다. 판정 재료가 이 값에 묶여 있습니다. 표마다 맨 아래 줄에 **자기 말로 한 줄 풀이**만 씁니다.

### 넣는 것

| 무엇 | 어디 (`blog/` 안) |
|---|---|
| 케이스 파일 — 이번 주에 준 자료 목록과 **꼭 들어갈 항목 다섯** | `cases/<케이스 이름>.yaml` |
| 원문 넷 — 논문 초록 둘 · 모델 소개 문서 하나 · 새 버전 안내 하나 (전부 연습용으로 지어낸 자료) | `cases/sources/week-01/` |
| 케이스 셋 — 통과해야 하는 것 하나, 거부돼야 하는 것 둘 | `case-01-standard` · `case-02-misquote`(인용이 틀림) · `case-03-opinion`(전부 의견으로 피해 감) |

내 말로 한 줄: (여기에 씁니다)

### 나오는 것

| 무엇 | 모양 |
|---|---|
| AI 가 내는 것 | 글이 아니라 **주장 목록** `claims[]`. 주장마다 네 칸: 주장(`text`) · 종류(`kind`: finding · benchmark · capability · limitation · opinion) · 출처(`source_id`) · 따온 문장(`quote`) |
| 형식 | `schema.json` — 작성 담당이 따라 쓰는 형식. `schema.strict.json` — 받은 뒤 우리가 검사하는 더 엄격한 형식(출처 이름 규칙, 의견에는 출처와 따온 문장이 비어 있어야 함) |
| 사람이 읽는 글 | AI 가 쓰지 않습니다. 글 만들기 단계가 주장 목록을 틀에 넣어 만듭니다 |
| 요청 기록 | `requests/<요청 id>/` — 단계마다 끝날 때 신호(`state.json`), 도구 호출·막힘 기록(`events.jsonl`), 진행표(`STATUS.md`) |
| 저장된 초안 | `samples/reference/<케이스 이름>.json` — 판정(`scripts/flow_check.py`)이 AI 대신 쓰는 초안 |

내 말로 한 줄: (여기에 씁니다)

### 지키는 것

AI 가 **고칠 수 없는** 것 넷입니다. 읽기는 막지 않습니다.

| 무엇 | 왜 |
|---|---|
| `cases/sources/` 원문 | 여기를 고칠 수 있으면 "따온 문장이 원문에 그대로 있나" 검사가 뜻을 잃습니다 |
| `samples/reference/` 저장해 둔 초안 | 비교의 기준입니다 |
| `.claude/` 의 설정 파일과 장치 코드 | 막는 장치 자신입니다. 같은 폴더의 명령(`commands/`)·하위 에이전트(`agents/`)·스킬(`skills/`)은 뒤 차시에 Claude 가 짓는 자리라 막지 않습니다 |
| `baseline.json` | "예전보다 나빠졌나" 를 재는 기준 점수입니다 |

이 장치는 Claude Code 안에서 쓰기를 막습니다. 다른 편집기나 다른 프로그램으로 고치는 것까지 막지는 못합니다.
